# CPT & HCPCS Procedure Coding Taxonomies & Fee Schedules

## 1. Scope & Definitions

Current Procedural Terminology (CPT), maintained by the American Medical Association (AMA), and Healthcare Common Procedure Coding System (HCPCS), maintained by CMS, describe medical, surgical, and diagnostic services rendered to patients.

### Coding Categories
- **CPT Category I:** Standard approved clinical procedures (5-digit numeric, e.g., `99213`).
- **CPT Category II:** Supplemental tracking performance metrics (e.g., `3008F`).
- **CPT Category III:** Emerging medical technologies (e.g., `0500T`).
- **HCPCS Level II:** Non-physician services, medical devices, ambulance, DME (e.g., `A0428`, `E0601`).

## 5. Procedural Modifiers

| Modifier | Description | Clinical Application |
|:---------|:------------|:---------------------|
| `-25` | Significant, separately identifiable E&M service by same physician on same day | E&M + minor procedure |
| `-50` | Bilateral procedure | Performed on both eyes, limbs, kidneys |
| `-59` | Distinct procedural service | Independent service during same session |
| `-LT` | Left side | Anatomical specificity |
| `-RT` | Right side | Anatomical specificity |
